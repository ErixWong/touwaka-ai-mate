# Tracking 跟踪目录说明

本目录保留历史性的跟踪结构，但当前项目的主要过程留痕已经迁移到 [`../tasks/`](../tasks/)。

## 当前定位

- `tracking/` 当前不是主要使用中的任务体系。
- 它保留为低活跃目录，用于存放少量历史跟踪材料或未来需要恢复的轻量跟踪结构。
- 若需要记录完整任务过程，应优先使用 [`../tasks/`](../tasks/)。

## 当前结构

```text
tracking/
├── README.md
└── completed/
```

## 使用建议

- 新任务：放 `docs/tasks/active/`
- 已完成任务：归档到 `docs/tasks/archived/`
- `tracking/` 仅在确有轻量历史记录需求时使用
